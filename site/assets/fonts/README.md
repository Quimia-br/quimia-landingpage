# Fontes do site

Arquivos woff2 hospedados aqui para o site não depender do Google Fonts. Todas as famílias usam a licença SIL Open Font License 1.1 (OFL), que permite usar e redistribuir.

| Arquivo | Família | Estilo e peso | Uso |
|---|---|---|---|
| `nunito-variable.woff2` | Nunito | normal, 200 a 1000 (variável) | títulos |
| `pt-sans-400.woff2` | PT Sans | normal, 400 | texto |
| `pt-sans-700.woff2` | PT Sans | normal, 700 | texto em negrito |
| `nunito-italic-variable.woff2` | Nunito | itálico, 200 a 1000 (variável) | `<em>` da página da empresa |
| `reem-kufi-variable.woff2` | Reem Kufi | normal, 400 a 700 (variável) | marca |

Só o subconjunto latino, que cobre o português. Origem: fonts.google.com (Nunito, PT Sans e Reem Kufi). As declarações `@font-face` ficam no começo de `css/user.css`, `css/business.css`, `css/privacy.css` e `css/support.css`.
